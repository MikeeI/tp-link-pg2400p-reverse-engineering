## Usable static map

A full aligned little-endian u32 scan finds 39,356 words in `0x63000000`–`0x633a8d6b`.
The working mapping is `static address = 0x63000000 + raw payload offset`.
The count is supporting evidence only because a flat raw image can contain accidental integer matches.
The map is independently corroborated by the raw pointer table at offset `0xd4`.
Its exact bytes are `182c0063cc2a0063282f0063985a0063605a0063245a0063e8590063`.
Those little-endian pointers resolve to `0x63002c18`, `0x63002acc`, `0x63002f28`, `0x63005a98`, `0x63005a60`, `0x63005a24`, and `0x630059e8`.
Each resolved target begins a valid Ghidra LE Xtensa function prologue.
At raw offset `0x2c18`, bytes `3661008c2288e2ac78929306` decode as `entry a1,0x30; beqz.n; l32i.n; beqz.n; l16si`.
At raw offset `0x2c2f`, bytes `8126f5` decode as `l32r a8,0x630000c8`.
The `l32r` reference is an in-image code-to-literal edge and independently agrees with the proposed base.
At raw offsets `0x2acc`, `0x2f28`, `0x5a98`, and `0x2d500`, valid LE functions begin with `entry`.
The same five 1.1.0 seeds produce no Ghidra BE instruction under `Xtensa:BE:32:default`.

## Architecture and entry boundary

[confirmed] The raw payload is structurally compatible with 32-bit little-endian Xtensa under the installed default language.
[likely] The CPU is the `xtensa8` family named by independent official container and raw strings, with a 32-bit little-endian ISA state.
[unresolved] The exact Xtensa core option, ABI, physical flash address, and runtime load address are not encoded in the raw payload.
[unresolved] No reset entry or exception-vector owner is proven.
The pointer table at raw offset `0xd4` is a candidate dispatch table, not a promoted reset-vector claim.
[unresolved] The raw Binary importer creates one executable block and exposes no section table, so global code/data boundaries remain unproven.
Valid code begins at least at raw offsets `0x2c18`, `0x2acc`, `0x2f28`, `0x5a98`, and `0x2d500`.
String and pointer regions are data candidates, not a complete component or segment map.
